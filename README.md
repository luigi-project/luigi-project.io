# Luigi Landing Page

The marketing landing page and blog for [Luigi](https://github.com/luigi-project/luigi),
served at **https://luigi-project.io** and deployed via Netlify.

This is a standalone [Eleventy (11ty)](https://www.11ty.dev/) static site. It has no
dependency on the Luigi framework packages — the only Luigi references are outbound links
to `https://docs.luigi-project.io`.

## Repository layout

```
.
├── blog/                 # Canonical blog post source (YYYY-MM-DD-slug.md)
├── dev/                  # 11ty site source and build tooling
│   ├── src/              # Templates (Handlebars), assets, layouts
│   ├── scripts/          # copy-blog.js, generate-feeds.js
│   ├── eleventy.config.js
│   └── package.json
├── public/               # Build output (gitignored; regenerated by the build)
├── build.sh              # Netlify build entry point
└── netlify.toml          # Netlify config
```

`public/` is **not** committed — it is generated by the build and rebuilt by Netlify on
every push. A fresh clone needs `cd dev && npm install && npm run build` before `public/`
contains a deployable site.

## Local development

```bash
cd dev
npm install
npm start          # build + watch + local server
```

To produce a one-off production build:

```bash
cd dev
npm run build      # runs copy-blog.js, compiles SCSS/JS, and runs 11ty
```

Node `>=20.19.0` (see `.nvmrc`).

## Adding a blog post

Create a markdown file in the repo-root `blog/` folder named `YYYY-MM-DD-page-slug.md`.
At build time `dev/scripts/copy-blog.js` copies it into `dev/src/blog/` and 11ty renders
it to `public/blog/<slug>/`. There is no scaffolder — you write the file by hand.

Front matter sets the SEO title, description, and author (single value or list). `layout`
must be `blog`. The excerpt shown on the overview page is separated from the body with an
`<!-- Excerpt -->` marker.

```markdown
---
title: Our first blog entry
seoMetaDescription: This is our first blog entry and it introduces our new blog section.
author:
  - Name 1
  - Name 2
layout: blog
---

This is a collection of advanced use cases and example implementations. If you are new to
Luigi, take a look at our [Getting Started](https://docs.luigi-project.io/docs/getting-started) section first.
<!-- Excerpt -->

Body content of the post goes here.

1. one
2. two
3. three
```

RSS, Atom, and JSON feeds are generated automatically from all posts by
`dev/scripts/generate-feeds.js` during the build.

## Deployment

Netlify builds via `build.sh` (`cd dev && npm ci && npm run build`) and publishes
`public/`. The `netlify.toml` `ignore` check skips a deploy when a push touches nothing in
this repository.
